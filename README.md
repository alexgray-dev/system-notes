# System Notes

A personal reference library of system notes, commands, and snippets for everyday work.

## What's inside

This repo collects the notes I rely on daily. Everything here is curated and battle-tested — worth a skim before touching a production box:

- **Linux** — essential shell commands, process management, permissions, and troubleshooting (OOM kills, full disks, dropped network connections)
- **Git** — daily basics plus the advanced workflow: rebasing, bisect, hooks, and reflog recovery
- **Networking** — HTTP deep dives and DNS resolution paths, from the first packet to the final answer
- **Python** — trusted snippets for automation, packaging, and performance
- **Scripts** — the backup and cleanup scripts I run on every server I manage

It also holds notes spanning many other languages and platforms — Bash, Go, Rust, C, Java, JavaScript, SQL, Docker, Kubernetes, Nginx, systemd, and cron — all in one place.

system-notes/
